# 🩺 Diabetes Risk Data Analysis Project

This project uses a health-related dataset to explore patterns, correlations, and trends associated with the risk of developing diabetes. The dataset contains clinical, genetic, and lifestyle features. Analysis is done using **Pandas**, **Matplotlib**, and **Seaborn** in Python.

---

## Dataset

- **File:** `diabetes_dataset00.csv`
- **Dataset Source:** [Kaggle](https://www.kaggle.com/datasets/ankitbatra1210/diabetes-dataset/)
- **Rows:** Each row represents one patient
- **Columns:** 30+ features including:
  - Medical history
  - Glucose and insulin levels
  - Lifestyle indicators (e.g. smoking, alcohol, diet)
  - Genetic and family factors
